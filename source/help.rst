Demander de l'aide
===========================

Coincés ? Perdus ? Un problème ?

Vous pouvez demander de l'aide !
* via le Discord officiel de l':ref:`IDFMwiki`, salon #faq (n'oubliez pas le tag ``SVG``)
* via GitHub en ouvrant une issue (n'oubliez pas le label ``question``)
* (déconseillé) *via l'IDFMwiki, page de Discussion*

.. tip::
    N'hésitez pas à consulter la :ref:`FAQ <faqref>` ! Peut-être que votre question a déjà été posée auparavant !
