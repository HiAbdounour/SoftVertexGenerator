Thèmes de ligne
======================

Le Soft Vertex Generator fournit quatre thèmes :
- le thème RER
- le thème METRO
- le thème TRAM
- le thème BUS

Un cinquième thème sera ajouté.

Les thèmes ont été produits en fonction des besoins de l':ref:`IDFMwiki`. Il n'est donc pas prévu d'en ajouter d'autres, sauf éventuellement en cas d'ajout de nouveau mode de transport en Île-de-France.

Vous avez toujours la possibilité de créer votre propre thème. Néanmoins, des connaissances en programmation Python et dans l'élaboration des SVG est requise.
Cette documentation ne fournit pas de ressources pour créer votre propre thème. Vous pouvez toutefois vous baser sur les thèmes existants.
