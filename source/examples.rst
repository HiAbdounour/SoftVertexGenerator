Exemples de fichiers XML
============================

En téléchargeant le Soft Vertex Generator, vous disposez d'un exemple de fichier XML (``bracket.xml``) avec sa génération (``output.svg``) et son ImageMap (``ImageMap_output.svg``).
Cet exemple est assez complet pour le thème BUS. Vous pouvez consulter le fichier XML et jouer avec pour découvrir l'outil.

Le :ref:`tutoriel <debut_tuto>` de cette documentation donne un deuxième exemple beaucoup plus simple.

Enfin, vous avez accès à une `base de fichiers XML <https://github.com/HiAbdounour/SoftVertexGenerator_IDFM>` contenant les fichiers XML de lignes réelles, donc aussi complexes qu'elles soient.
Vous trouverez donc plusieurs exemples de "comment on fait ça".

N'hésitez pas aussi à consulter la :ref:`FAQ <faqref>` !
