Installation et prérequis
===========================

.. important::
    Pour utiliser le Soft Vertex Generator, il est nécessaire d'avoir un **ordinateur** avec `Python <https://www.python.org/downloads/>`_ installé dessus.

Obtenir le Soft Vertex Generator
-----------------------------------

Le Soft Vertex Generator est un projet open source disponible sur GitHub .

Pour obtenir l'outil, vous pouvez cliquer sur `ce lien <https://github.com/HiAbdounour/SoftVertexGenerator/releases>`__ .
Ensuite, sélectionnez la version de votre choix. Les versions sont classées **de la plus récente à la plus ancienne**. Chaque version
présente les changements apportés par rapport aux versions précédentes.

.. tip::
    Il est recommandé d'utiliser la version la plus récente.

Une fois la version choisie, **téléchargez le dossier .zip de la version** et dézippez-le. Vous avez désormais l'outil.

Prérequis
----------------

Pour utiliser le Soft Vertex Generator, vous aurez besoin d'une **version stable** de :ref:`Python` installée sur votre ordinateur.

Le Soft Vertex Generator a été devéloppé sur Python 3.14 mais les versions 3.12 et 3.13 fonctionnent correctement.
Pour les versions plus anciennes, aucune garantie de fonctionnement n'est assurée.
Pour la nouvelle version 3.15 (ou 3.26), a priori, il n'y a pas de problème de compatibilité.

Utilisation
------------------

Les prochaines pages de cette documentation présentent le fonctionnement du Soft Vertex Generator.

Mettre à jour le SVG
--------------------------

Pour mettre à jour le Soft Vertex Generator, il est nécessaire de **changer le dossier**. Une solution simple consiste à supprimer le dossier
de l'ancienne version et de récupérer le nouveau dossier sur `GitHub <https://github.com/HiAbdounour/SoftVertexGenerator/releases>`__.
